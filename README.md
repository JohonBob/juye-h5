# 麟州雅集 · 巨野 —— 国风文旅 H5

《H5交互设计》课程作业 · 文旅主题 · 山东菏泽巨野

## 在线访问

👉 **https://johonbob.github.io/juye-h5/**

## 作品简介

以「麒麟之乡」巨野为主题的国风交互 H5，竖屏 9:16 设计，共 6 个页面：

| 页 | 主题 | 内容 |
|---|---|---|
| 壹 · 启幕 | 封面 | 金山背景 · 竖排标题 · 开启按钮 |
| 贰 · 溯源 | 麟乡溯源 | 大野泽 / 西狩获麟 / 麒麟之乡 |
| 叁 · 揽胜 | 山水胜景 | 金山景区 / 永丰塔 / 白虎山 |
| 肆 · 问艺 | 文脉画乡 | 工笔牡丹 / 农民绘画之乡 / 非遗民俗 |
| 伍 · 寻味 | 麟城风味 | 罐子汤 / 壮馍 / 米豆沫 |
| 陆 · 雅集 | 尾页 | 朱砂印章动画 · 分享与重游 |

## 交互设计

- 上下滑动翻页（触摸 / 滚轮 / 方向键 / 圆点导航）
- 15 个国风卷轴弹窗（热点卡片点击触发）
- 小麒麟吉祥物「麟麟」：SVG 拟人动卡通形象，眨眼、漂浮、火焰尾摆动，
  4 种表情（微笑 / 开心 / 惊讶 / 馋嘴）随页面切换，点击有彩蛋台词

## 视觉规范

- 配色：朱砂 `#c0392b` · 赭金 `#c9a063` · 宣纸 `#f6efdd` · 黛青 `#2f4b4e`
- 字体：楷体 / 宋体，竖排书法标题，印章元素
- 背景：5 张 AI 生成国风插画（金山、麒麟获麟台、永丰塔、工笔牡丹、罐子汤）

## 本地运行

直接用浏览器打开 `index.html` 即可，或：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
